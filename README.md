# Trello MCP

MCP-сервер для Trello: доски, списки, карточки, чек-листы, комментарии, поиск.

## Установка

```
npm install && npm run build
claude mcp add --scope user trello -- node /абсолютный/путь/к/build/index.js
```

## Шаг 0. API-ключ (один раз, вручную)

Trello выдаёт ключ только владельцу аккаунта, это нельзя автоматизировать.

1. В Trello должна быть рабочая область (Workspace). Если нет: «Создать» → «Создать рабочую область».
2. https://trello.com/power-ups/admin/new → «Мое приложение не использует возможности улучшения» →
   название, рабочая область, email, автор → «Создать».
3. «Авторизация в Trello» → «Создать новый API-ключ» → «Сгенерировать API-ключ».
4. В «Одобренные ресурсы» добавьте `http://localhost:8765` (нужно только для автоматического режима).
5. Скопируйте «Ключ API» (32 символа) в `~/.config/trello-mcp/config.json`:
   ```json
   { "apiKey": "ваш_ключ" }
   ```
   или задайте переменную окружения `TRELLO_API_KEY`.

Секретный ключ (64 символа) серверу не нужен.

## Подключение аккаунта: выберите способ

Пока Trello не подключён, любой инструмент отвечает сообщением с выбором. Подключиться можно инструментом
`trello_connect`.

### Автоматически: `trello_connect {"mode":"auto"}`

Что происходит (каждый шаг приходит в виде live-лога и в итоговом ответе):

1. Проверка API-ключа.
2. Запуск локального приёмника токена на `localhost:8765`.
3. Открытие браузера со страницей согласия Trello, вам нужно нажать «Разрешить».
4. Браузер возвращает токен на локальный адрес.
5. Проверка токена запросом к Trello.
6. Токен сохраняется в `~/.config/trello-mcp/config.json` (права 600).
7. Вкладка подключения закрывается автоматически (на macOS через AppleScript: Chrome, Safari, Brave, Edge, Arc и др.; на других ОС страница пробует закрыться сама). При первом запуске macOS может спросить разрешение на управление браузером.

Если браузер не открылся, ссылка есть в логе. Ожидание подтверждения: 3 минуты.

### Вручную: `trello_connect {"mode":"manual"}`

1. Вызов без `token` вернёт инструкцию и ссылку.
2. Откройте ссылку в браузере, где вы вошли в Trello, нажмите «Разрешить».
3. Скопируйте показанный токен (~76 символов).
4. Вызовите `trello_connect {"mode":"manual","token":"<токен>"}`: сервер проверит токен и сохранит его.

### Режим по умолчанию

Чтобы не выбирать каждый раз: `TRELLO_AUTH_MODE=auto|manual` или `"authMode"` в config.json.
С `auto` сервер сам запускает подключение при первом же вызове любого инструмента.

## Язык сообщений

Сервер отвечает на том языке, на котором вы пишете, а если определить не удалось, на языке системы, иначе на английском.
Поддерживаются английский, русский и украинский (инструкции, лог подключения, страница в браузере).

Порядок выбора:
1. `TRELLO_LANG` или `"lang"` в config.json: язык закреплён принудительно, остальное игнорируется.
2. Параметр `lang`: на каждом вызове инструмента Claude передаёт код языка вашего сообщения (`ru`, `uk`, `en`…),
   сервер запоминает его на сессию. Сервер не видит ваш текст, поэтому это делает модель по инструкции сервера.
3. Язык системы: `LC_ALL`, `LC_MESSAGES`, `LANG`, затем локаль ОС.
4. Английский.

Для языка без словаря (например, `es`) сообщения идут на английском, а Claude пересказывает их на вашем языке.
Описания инструментов всегда английские: их читает модель, а не пользователь. Данные Trello не переводятся.
Добавить язык: словарь в `src/i18n.ts` (тест `npm test` проверит, что в нём есть все ключи).

## Статус и отладка

`trello_status` показывает, подключён ли сервер, настроен ли ключ, режим по умолчанию, язык сообщений и последние 30 строк лога.
Переподключение: `trello_connect` с `force: true`.

Отозвать доступ: trello.com → Аккаунт → Настройки → Приложения.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TRELLO_API_KEY` | API-ключ (приоритетнее файла) |
| `TRELLO_TOKEN` | токен (приоритетнее файла) |
| `TRELLO_AUTH_MODE` | `auto` или `manual` |
| `TRELLO_AUTH_PORT` | порт локального приёмника (по умолчанию 8765) |
| `TRELLO_LANG` | принудительный язык сообщений: `en`, `ru`, `uk` |

## Инструменты (40)

Подключение: `trello_status`, `trello_connect`.
Доски: `list_boards`, `get_board`, `create_board`, `update_board`, `delete_board`, `copy_board`, `get_board_members`.
Списки: `get_lists`, `create_list`, `update_list` (имя, позиция, архив), `archive_list`, `copy_list`.
Карточки: `get_cards`, `get_card`, `create_card`, `update_card` (в т.ч. перенос на другую доску, даты начала и срока),
`copy_card`, `delete_card`, `set_cover`, `add_comment`, `get_comments`, `add_attachment`.
Метки: `get_labels`, `create_label`, `add_label`, `remove_label`.
Чек-листы: `create_checklist`, `add_checklist_item`, `set_checkitem_state`, `delete_checklist`.
Пользовательские поля: `get_custom_fields`, `create_custom_field` (text, number, date, checkbox, list; Power-Up включается сам),
`set_custom_field` (пустая строка очищает значение).
Участники: `get_board_members`, `invite_member`, `assign_member`, `unassign_member`, `remove_member_from_board`.
Поиск: `search` (с `limit`, `page`, `boardId`).

### Большие доски: пагинация и фильтры

`get_cards` без `limit` возвращает массив. С `limit` (и `offset`) возвращает
`{total, offset, returned, hasMore, cards}`: повторяйте вызов с `offset += limit`, пока `hasMore` истинно.
`filter` = `open` | `closed` (архив) | `all`; `compact=true` убирает описания. Читается до 1000 карточек.
`get_comments` листается через `limit` и `before` (id последнего комментария предыдущей страницы).

### Подсказки клиенту и надёжность

Чтение помечено `readOnly`, необратимые удаления (`delete_card`, `delete_board`, `delete_checklist`,
`remove_member_from_board`) помечены `destructive`. `invite_member` отправляет приглашение на email: вызывайте его
только по явной просьбе. При лимите Trello (HTTP 429) запрос повторяется до 3 раз, таймаут запроса 30 секунд.

## Запуск через npx

Пакет готов к публикации (`npm pack` проверен: ставится в чистую папку и запускается). Имя в `package.json`:
`claude-trello-mcp-server`; перед `npm publish` проверьте, что оно свободно (`npm view <имя>`), и войдите в npm (`npm login`).
После публикации:

```
claude mcp add --scope user trello -- npx -y claude-trello-mcp-server
```

Без публикации: `npm pack`, затем `npx -y ./claude-trello-mcp-server-1.2.0.tgz` или путь к `build/index.js`, как выше.
